AI agents and closed terminals leave dev servers and Docker containers running in the background. Ghosts shows what each one costs in CPU, memory and power, and stops it with one key. AI agent 和關掉的終端機，常把 dev server 和 Docker 容器留在背景執行。Ghosts 讓你看到每一個吃了多少 CPU、記憶體和電，按一個鍵就關掉。

curl -fsSL https://ghosts.xamjiang.com/install | bash

Then run ghosts. macOS 13+ and Linux (amd64, arm64). 裝好後輸入 ghosts。支援 macOS 13 以上和 Linux（amd64、arm64）。

Features功能

👻 Spot the real ghosts👻 認出真正的幽靈

The terminal is gone, the agent is done, but the server is still up. Ghosts marks processes that outlived their session as detached, and shows which project they belong to, how long they've been running and the full command that started them.

終端機關了、agent 跑完了，server 卻還在：Ghosts 會把這種脫離 session 的程序標成 detached，並告訴你它屬於哪個專案、跑了多久、完整的指令是什麼。

🔋 See what's draining power🔋 看誰在吃電

CPU and memory for every service, plus each process's actual power draw on Apple Silicon, children included. Press s to sort by power.

每個服務的 CPU、記憶體，以及 Apple Silicon 上每個程序的實際耗電（含子程序），按 s 依耗電排序。

🐳 Docker included🐳 Docker 也一起管

Containers are grouped by compose project, and ports proxied by Docker Desktop map back to the real container. Stop a whole compose project at once. Works with Docker Desktop, OrbStack, Colima and Docker Engine.

容器依 compose 專案分組，Docker Desktop 代理的 port 會對回真正的容器，一次停掉整個 compose 專案。支援 Docker Desktop、OrbStack、Colima 和 Docker Engine。

🛑 Stops things safely🛑 安全地關掉

  • x sends SIGTERM, and only offers SIGKILL if the process is still alive after 3 seconds
  • Checks the start time first, so a reused PID never takes down the wrong process
  • Stops containers with docker stop, never by killing Docker Desktop
  • Hides apps and system services, and warns before stopping one
  • x 先送 SIGTERM，3 秒沒結束才詢問要不要 SIGKILL
  • 送出前比對程序的啟動時間，PID 被重複使用也不會誤殺
  • 容器用 docker stop，不會誤殺 Docker Desktop
  • App 和系統服務預設隱藏，要停之前會多一句警告

Get started開始使用

New to the terminal? Start here第一次用終端機？從這裡開始

Four steps, about a minute.四個步驟，大約一分鐘。

  1. Open a terminal打開終端機

    macOS: press ⌘ Space to open Spotlight, type Terminal and press Return. macOS：按 ⌘ 空白鍵 打開 Spotlight，輸入「終端機」（或 Terminal），按 Return。

    Ubuntu and most Linux desktops: press Ctrl Alt T. Ubuntu 和大多數 Linux 桌面：按 Ctrl Alt T。

  2. Install Ghosts安裝 Ghosts

    Paste this line into the terminal and press Enter:把這行貼進終端機，按 Enter：

    curl -fsSL https://ghosts.xamjiang.com/install | bash

    If it asks for a password, type the one you use to log in to your computer and press Enter. Nothing shows up on screen while you type a password. That's normal. When you see ✓ ghosts … is installed., it's done. 如果要求輸入密碼，請輸入你登入電腦用的密碼，再按 Enter。輸入密碼時畫面上不會出現任何字，這是正常的。看到 ✓ ghosts … is installed. 就是裝好了。

  3. Run it執行

    Type ghosts and press Enter:輸入 ghosts，按 Enter：

    ghosts

    Ghosts opens right inside the terminal window and lists everything that's listening on a port. You only install it once. From now on, open a terminal and type ghosts whenever you want to use it. Ghosts 會直接在終端機視窗裡打開，列出所有正在 listen port 的程序。安裝只要做一次，以後想用的時候，打開終端機、輸入 ghosts 就好。

Getting command not found: ghosts?出現 command not found: ghosts？

On a Mac without Homebrew, and on some Linux systems, the script puts Ghosts in ~/.local/bin, and your terminal may not look for programs there yet. Run this once, then open a new terminal window and try ghosts again: 在沒有 Homebrew 的 Mac 和部分 Linux 上，script 會把 Ghosts 裝到 ~/.local/bin，但終端機可能還不會去那裡找程式。執行下面這行一次，再開一個新的終端機視窗輸入 ghosts 就可以了：

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

That's for the Mac's default shell, zsh. On Linux with bash, use ~/.bashrc instead of ~/.zshrc. Until then, you can run it with its full path: ~/.local/bin/ghosts. 這是給 Mac 預設的 zsh 用的；Linux 上用 bash 的話，把 ~/.zshrc 換成 ~/.bashrc。在那之前，也可以用完整路徑執行：~/.local/bin/ghosts。

Install安裝

One line, real updates一行安裝，正常更新

The script uses your system's own package manager, so Ghosts updates like everything else.Script 會用系統原本的套件管理器安裝，之後的更新方式和其他軟體一樣。

curl -fsSL https://ghosts.xamjiang.com/install | bash

What the script doesScript 會做什麼

Ubuntu, Debian Adds the ghosts APT repository and installs the package. Asks for your sudo password. Updates with apt upgrade. 加入 ghosts 的 APT repo 並安裝。會要 sudo 密碼，之後用 apt upgrade 更新。
With Homebrew有 Homebrew Runs brew install xamjiang/tap/ghosts. Updates with brew upgrade. 執行 brew install xamjiang/tap/ghosts。之後用 brew upgrade 更新。
Anything else其他系統 Downloads the release binary, verifies its checksum and puts it in ~/.local/bin. Run the script again to update. 下載 binary、驗證 checksum，裝到 ~/.local/bin。再跑一次 script 就會更新。

Read the script before you run it. 執行前可以先看 script 內容。

Set up APT yourself自己設定 APT

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ghosts.xamjiang.com/apt/key.gpg | sudo tee /etc/apt/keyrings/ghosts.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/ghosts.gpg] https://ghosts.xamjiang.com/apt stable main" | sudo tee /etc/apt/sources.list.d/ghosts.list
sudo apt update && sudo apt install ghosts
