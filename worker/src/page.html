👻 Ghosts

Find the dev servers and Docker containers you forgot to stop, see what they cost in CPU, memory and power, and stop them. For macOS and Linux.

curl -fsSL https://ghosts.xamjiang.com/install | bash

What the script does

Ubuntu, DebianAdds the ghosts APT repository and installs the package. Asks for your sudo password. Updates with apt upgrade.
With HomebrewRuns brew install xamjiang/tap/ghosts. Updates with brew upgrade.
Anything elseDownloads the release binary, verifies its checksum and puts it in ~/.local/bin. Run the script again to update.

Read the script before you run it.

Set up APT yourself

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ghosts.xamjiang.com/apt/key.gpg | sudo tee /etc/apt/keyrings/ghosts.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/ghosts.gpg] https://ghosts.xamjiang.com/apt stable main" | sudo tee /etc/apt/sources.list.d/ghosts.list
sudo apt update && sudo apt install ghosts
